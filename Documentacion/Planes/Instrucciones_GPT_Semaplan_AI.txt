Instrucciones base para configurar Semaplan en ChatGPT.

Modo recomendado para B2.

Usar un Custom GPT con GPT Actions y OAuth. Esta es la superficie
adecuada para que ChatGPT pueda crear tareas, marcar hábitos,
registrar avances, crear notas en Archivero y crear ítems en Baúl.

La App MCP queda como B1 de lectura. Puede seguir usándose para
consultas, pero no es la superficie recomendada para la B2 de
escritura.

Nombre sugerido.

Semaplan.

Texto exacto sugerido para pegar en el campo `Instructions` del GPT.

`Documentacion/Planes/Prompt_GPT_Semaplan_AI.txt`.

Base URL viva actual.

`https://cprdnxkkhuuhdispubds.supabase.co/functions/v1/semaplan-ai`.

Contrato OpenAPI para GPT Actions.

1. Usar como contrato principal:
   `Documentacion/Planes/OpenAPI_Semaplan_AI.yaml`.
2. Si se quiere validar el contrato vivo en runtime, revisar:
   `GET /openapi.json`.

Autenticación recomendada.

Usar OAuth. No copiar tokens personales en el GPT.

Valores.

- Authorization URL:
  `https://cprdnxkkhuuhdispubds.supabase.co/functions/v1/semaplan-ai/oauth/authorize`.
- Token URL:
  `https://cprdnxkkhuuhdispubds.supabase.co/functions/v1/semaplan-ai/oauth/token`.
- Scope B2 completo:
  `read write_tasks write_habits write_metas write_archivero write_baul`.
- Client ID:
  `semaplan-chatgpt` o el valor configurado en secreto.
- Client Secret:
  el mismo valor guardado en `SEMAPLAN_AI_OAUTH_CLIENT_SECRET`.

Secrets requeridos en Supabase Functions.

- `SEMAPLAN_AI_OAUTH_CLIENT_ID`.
- `SEMAPLAN_AI_OAUTH_CLIENT_SECRET`.
- `SEMAPLAN_AI_OAUTH_LOGIN_URL`.
- Valor recomendado para `SEMAPLAN_AI_OAUTH_LOGIN_URL`:
  `https://semaplan.com/login.html`.

Flujo final para usuario en B2.

1. En ChatGPT, crear o editar el Custom GPT `Semaplan`.
2. Pegar el contenido de `Prompt_GPT_Semaplan_AI.txt` en
   `Instructions`.
3. En `Actions`, pegar el contrato
   `OpenAPI_Semaplan_AI.yaml`.
4. Configurar autenticación OAuth con las URLs y credenciales de
   arriba.
5. Usar el scope B2 completo o solo los scopes que se quieran habilitar
   para ese GPT.
6. Guardar el callback URL que muestre ChatGPT en la configuración
   OAuth permitida de Semaplan, si el entorno lo exige.
7. Al conectar, ChatGPT redirige a Semaplan, el usuario inicia sesión
   si hace falta y confirma permisos.
8. El GPT queda habilitado para leer y ejecutar acciones B2.

Alcance deliberadamente fuera de B2.

- Borrar datos.
- Ediciones masivas.
- Cambios en Discoteca o Decoteca.
- Cambios estructurales de agenda o planes vinculados.
- Administración de tokens.

Compatibilidad.

- En ChatGPT Actions, usar OAuth y el OpenAPI de B2.
- En ChatGPT Apps o MCP remoto, mantener el uso B1 de lectura.
- El modo API key por `X-Semaplan-AI-Token` se mantiene para pruebas o
  scripts legacy fuera de Actions.
- En modo OAuth, cada autorización crea un token interno del usuario
  para auditar uso y revocar desde `Cuenta -> Integraciones IA`.

Notas.

- `GET /salud` sirve solo para chequeo técnico.
- `GET /openapi.json` no expone datos del usuario y puede usarse como
  referencia viva del contrato.
- La B2 registra mutaciones con idempotencia y auditoría en Supabase.
